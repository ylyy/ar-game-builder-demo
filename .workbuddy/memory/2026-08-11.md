# 2026-08-11

## retarget 算法切换为 kalidokit（vtube-sol 方案）
- 起因：用户问 vtube-sol（github.com/codevibersol-glitch/vtube-sol）用的什么方案，确认它 = MediaPipe Holistic + Three.js + @pixiv/three-vrm + **kalidokit** rigging（Vite，纯浏览器），即路线A 同一家族。用户要求"改成他这个算法"。
- 改动：
  1. `src/pose.ts`：PoseDetector → **HolisticDetector**（HolisticLandmarker，模型 public/models/holistic_landmarker.task 已下载 13MB，delegate CPU，wasm 本地化）。注意 HolisticLandmarkerOptions 无 numPoses/minTrackingConfidence/minHandPresenceConfidence。
  2. `src/retarget.ts`：自研 kiarina 算法整体替换为 kalidokit 三件套（Face/Pose/Hand.solve），输出弧度欧拉角 → 逐轴 lerp 平滑写入 VRM 骨骼；表情/眨眼/lookAt 一并接入。保留 Retargeter 公开接口（update/pause/resume/reset/applyRestPose/setMirrorX/setFlipY）+ setVideo。
  3. `src/main.ts`：改用 HolisticDetector、setVideo(video)、overlay 用 poseLandmarks。
  4. `index.html`：提示文案 Holistic。
- 关键坑（已踩并修复）：
  - kalidokit 的 video 参数只接受 HTMLVideoElement|null（传对象 → videoWidth undefined → NaN）。
  - VRM 无 ThumbIntermediate 骨骼（kalidokit 输出有，getNormalizedBoneNode null 自动跳过）。
  - flip 函数：归一化坐标镜像用 1-x，world 坐标用 -x。
- 结果：tsc --noEmit + vite build 通过；dev server 5173 HTTPS 冒烟验证各模块 200。
- 待用户实测：摄像头下全身/手势/表情驱动效果；若左右反用镜像按钮兜底。
